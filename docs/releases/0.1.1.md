# MathlibLink 0.1.1

- Reuse LeanLink's imported environments for evaluation and proof checking when supported.
- Prepare evaluation during imports, improve cleanup and remove unnecessary waits when reading installation output.
- Display sessions, declarations, values and expressions as expandable notebook summaries.

Existing MathlibLink session functions remain supported with LeanLink 1.2.5 or
later. The new environment interface and evaluator preparation require
[LeanLink PR #4](https://github.com/WolframInstitute/LeanLink/pull/4) until those
changes are released. Loading MathlibLink does not start Lean or install software.

Requires Wolfram Language 15.0 or later, Lean 4.35.0 and mathlib v4.35.0.
