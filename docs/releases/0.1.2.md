# MathlibLink 0.1.2

- Check the latest published LeanLink on every setup run and update older installations, including when mathlib is already installed. No LeanLink version or archive is pinned.
- Validate evaluator capabilities and request a kernel restart after updating a loaded LeanLink.
- Fix tutorial plots and quick-start examples using LeanLink's environment evaluator.
- Reevaluate documentation examples during builds and reject messages, unevaluated calls and unexpected failures before packaging or publishing.

Requires Wolfram Language 15.0 or later, the current LeanLink release,
Lean 4.35.0 and mathlib v4.35.0.
