# MathlibLink 0.1.2

- Fix tutorials and quick-start examples to work with the released LeanLink dependency. Evaluated lists now reach the plotting functions correctly.
- Reevaluate documentation examples during builds and reject messages, unevaluated calls and unexpected failures before packaging or publishing.
- Preserve automatic use of LeanLink's faster environment evaluator when that interface is available.

Requires Wolfram Language 15.0 or later, LeanLink 1.2.5 or later,
Lean 4.35.0 and mathlib v4.35.0.
